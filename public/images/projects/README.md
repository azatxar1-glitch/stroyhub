Фотографии объектов.

Удобно держать по папке на объект: `/images/projects/obj-01/cover.jpg`, `01.jpg`, `02.jpg`.
Пути указываются в `src/data/kamtehnostroy/projects.ts`:
`image` — обложка, `gallery` — дополнительные кадры.

Рекомендации: JPG или WebP, ширина 1600–2400 px.

Промпты для генерации — `docs/kamtehnostroy-images.md`.

Техническая достоверность кадров процесса — `docs/kamtehnostroy-images-tech.md`.
