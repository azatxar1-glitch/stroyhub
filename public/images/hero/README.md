Фотографии первого экрана.

Положите сюда файл (например `hero.jpg`) и укажите путь в
`src/data/kamtehnostroy/company.ts` → `hero.image: "/images/hero/hero.jpg"`.

Рекомендации: JPG или WebP, ширина 2400–3200 px, вес до ~600 КБ.
Кадр тёмный и контрастный — поверх него ложится крупный светлый заголовок.

Промпты для генерации — `docs/kamtehnostroy-images.md`.
