Фотогалерея.

Положите файлы сюда и укажите путь в `src/data/kamtehnostroy/gallery.ts` (поле `src`).
Там же задаётся категория и размер плитки (`span`: "tall" | "wide").

Рекомендации: JPG или WebP, ширина 1200–2000 px.

Промпты для генерации — `docs/kamtehnostroy-images.md`.

Техническая достоверность кадров процесса — `docs/kamtehnostroy-images-tech.md`.
